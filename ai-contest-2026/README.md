## 这份归档的真实性说明

本仓库保存的是 **当前可恢复的真实文件 + 基于既有对话内容整理的结构化纪要**，不应误称已经拿到 ChatGPT 所有历史对话逐字原文。部分较早讨论只留下会话总结或生成资产，纪要已明确区分。需要逐字级别的完整原始聊天存档，应以用户自行导出的原始对话记录补充后另行校核。
